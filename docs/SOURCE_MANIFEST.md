## Why These Sources

The list spans the core portfolio story:

- Classical ML fundamentals from Stanford CS229.
- Deep learning concepts from an open-source book.
- Transformer, BERT, GPT, and Llama technical papers for modern AI foundations.
- RAG and AI agent surveys for retrieval-augmented system design.
- NIST, OWASP, and Stanford HAI resources for responsible AI, safety, and governance.

Do not add pirated textbooks or unofficial mirrors. Prefer official university pages, official organization publications, arXiv author submissions, or open-source book sites.
